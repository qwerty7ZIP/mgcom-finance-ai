# План проекта MGCOM Finance AI

## 1. Текущий статус

Реализовано:

- авторизация пользователей через Supabase Auth;
- разделы:
  - `ИИ-ассистент` (`/`)
  - `Аналитика` (`/analytics`)
  - `Диаграмма` (`/diagram`)
  - `Карточка тендера` (`/tenders/[id]`)
  - `Админка` (`/admin`);
- AI-чат с server-side планированием выборок, markdown-ответами и диагностикой;
- история чатов: список слева, открытие, удаление, сохранение после первого сообщения;
- права доступа к разделам и админ-роль;
- CRUD пользователей в админке + смена пароля;
- диаграмма с будущими тендерами и переходом в карточку.

## 2. Цели ближайших этапов

1. **Усилить безопасность и управление доступом**
   - запрет удаления последнего админа;
   - аудит изменений прав/пользователей;
   - необязательное требование смены пароля при первом входе.

2. **Улучшить админку**
   - поиск и фильтрация пользователей;
   - роли/шаблоны прав (например, пресеты для отделов);
   - bulk-операции.

3. **Развитие аналитики**
   - дополнительные метрики и drill-down;
   - экспорт аналитических выборок;
   - серверные агрегации для больших объемов.

4. **Развитие AI-контура**
   - вынести словари агентств/проектов в отдельную конфигурацию;
   - тонкая настройка диагностического блока (режим для админа vs пользователя);
   - оптимизация long-context запросов и агрегаций на больших данных.

5. **Операционная готовность**
   - healthcheck/observability;
   - централизованные инструкции по backup/restore;
   - финализация прод deployment runbook.

## 3. Принципы развития

- обновлять документацию вместе с кодом;
- держать обратную совместимость по метаданным пользователей;
- критичную бизнес-логику фильтров/доступов оставлять на сервере;
- UI делать максимально прозрачным по состояниям прав и ошибок.
