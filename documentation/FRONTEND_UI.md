# Фронтенд и UI MGCOM Finance AI

## 1. Основные страницы

- `/` - раздел `ИИ-ассистент` (чат + история чатов).
- `/analytics` - аналитический дашборд.
- `/diagram` - диаграмма тендеров (Gantt).
- `/tenders/[id]` - карточка тендера.
- `/account` - личный кабинет (в т.ч. смена своего пароля).
- `/admin` - админ-панель пользователей.
- `/auth/sign-in` - вход.

## 2. Навигация и доступы

- `AppHeader` показывает только доступные пользователю разделы.
- Пункт `Админка` виден только при `is_admin = true`.
- Защита всех внутренних страниц делается через `ProtectedLayout`.
- Если у пользователя нет прав ни к одному разделу, показывается:
  - `Попросите администратора о доступе`.

## 3. Раздел ИИ-ассистент (`Dashboard`, `ChatPanel`)

### Основной сценарий

- пользователь задает вопрос на русском языке;
- запрос уходит в `/api/chat`;
- сервер строит план выборок, тянет данные из БД и формирует markdown-ответ;
- в UI рендерится структурированный ответ (списки/таблицы/выводы).

### Возможности интерфейса

- список чатов слева;
- кнопка `Новый чат` (создает черновик);
- сохранение чата только после первого сообщения;
- открытие предыдущего чата;
- удаление старого чата;
- markdown-таблицы в ответах с визуальными границами строк/столбцов.

### Примечание по сохранению

- основной режим: серверное хранение через `/api/chats*`;
- fallback-режим: локальное хранение (`localStorage`) при ошибках серверного API хранения.

## 4. Раздел Аналитика (`analytics/*`)

Секции:

- `Клиенты`
- `Контакты`
- `Тендеры`
- `Менеджеры`

Реализованы карточки метрик и графики (`recharts`), с учетом текущих фильтров по периоду/агентствам/менеджеру (где применимо).

## 5. Раздел Диаграмма (`diagram/TendersGantt.tsx`)

- горизонтальный timeline с масштабами `дни/недели/месяцы`;
- красная вертикальная линия текущей даты;
- кнопка `Сегодня`:
  - центрирует текущую дату по горизонтали,
  - скроллит к ближайшему тендеру по старту;
- sticky-колонка `Тендер` (слева);
- отображение `Клиент / Проект` + agency/manager;
- будущие тендеры:
  - `futureStart = start + 1 год`,
  - `futureEnd = futureStart + 3 недели`,
  - пунктирная менее яркая плашка;
- попап возле курсора для future-плашек;
- клик по названию/плашке открывает карточку тендера.

## 6. Карточка тендера (`/tenders/[id]`)

- загрузка по `id_pf`, fallback по `id`;
- заголовок: `Клиент / Проект`;
- кнопка `Посмотреть в Планфикс` (если есть `id_pf`);
- вывод всех видимых полей кроме `id_pf`;
- правый верхний блок активности:
  - `Активный клиент {agency}` из `active_list`,
  - каналы (performance/context/.../creative), где значение `true`.

## 7. Админка (`admin/AdminPanel.tsx`)

Возможности:

- создание пользователей;
- удаление пользователей;
- смена пароля пользователю;
- выдача/снятие `Админ`;
- выдача/снятие доступов к:
  - `Диаграмма`
  - `ИИ-ассистент` (в metadata ключ доступа остается `tables`)
  - `Аналитика`.

## 8. Тема и стили

- Tailwind CSS + глобальные токены из `globals.css`;
- светлая и темная тема;
- единый визуальный стиль карточек, таблиц, контролов и статусов загрузки/ошибок.
