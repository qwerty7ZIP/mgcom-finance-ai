# Документация MGCOM Finance AI

Актуальная документация по текущему состоянию проекта.

## Что покрыто в документации

- архитектура Next.js + Supabase + YandexGPT;
- API маршруты приложения;
- страницы и UI-паттерны;
- модель данных и таблицы;
- запуск локально и деплой;
- текущий roadmap.

## Карта файлов

- `README.md` - этот файл.
- `ARCHITECTURE.md` - как устроено приложение и потоки данных.
- `API_AND_INTEGRATIONS.md` - описание API:
  - `/api/data`
  - `/api/chat`
  - `/api/chats`
  - `/api/chats/[chatId]`
  - `/api/chats/sync`
  - `/api/admin/users`
- `FRONTEND_UI.md` - страницы, компоненты, поведение интерфейса.
- `DATA_MODEL.md` - таблицы `clients`, `contacts`, `tenders`, `active_list`, метаданные доступов пользователей.
- `SETUP_AND_RUN.md` - окружение, запуск, Docker, типовой деплой.
- `PLAN.md` - текущее состояние и список направлений развития.

## Быстрый контекст

Сервис включает:

- раздел `ИИ-ассистент` (`/`) с AI-чатом и историей диалогов;
- раздел `Аналитика` (клиенты, контакты, тендеры, менеджеры);
- раздел `Диаграмма` (Gantt тендеров + будущие тендеры + переход в карточку);
- карточку тендера `/tenders/[id]`;
- админку `/admin` для управления пользователями и доступами.

## Важно про актуальность

При изменениях в коде сначала обновляется реализация, затем соответствующие файлы в `documentation/`.
